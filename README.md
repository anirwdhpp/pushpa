# Pushpa — Scented Candles & Gift Hampers

An elegant storefront web page for artisanal soy candles and handcrafted gift hampers.

## Features
- Modern typography with Cormorant Garamond & Inter
- Responsive luxury layout with ambient candle glow animations
- Curated scent notes and hamper product showcase
- Light/Dark mode dynamic styling
- Smooth interactions and micro-animations

## Viewing
Open `index.html` in any web browser or deploy to GitHub Pages.
